# Security policy

These projects are public, interactive demonstrations. They are not intended
to be deployed as-is for a production community or customer-facing service.

Please do not include API keys, passwords, personal data, or other secrets in
issues or pull requests. Report suspected security issues privately to
security@pagelove.com rather than opening a public issue.

The demos use seeded identities and simplified authorization examples. Review
and replace those assumptions before using any demo with real user data.
